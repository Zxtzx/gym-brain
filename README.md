# Gym Brain

A beginner Python fitness analytics project that calculates workout volume and estimated one-rep max from terminal input.

## Current Version

v0.2.5 — improved beginner baseline

## Current Features

- Track multiple workout sets
- Accept exercise names with spaces, like Bench Press
- Reject exercise names with numbers or symbols
- Calculate estimated 1RM using the Epley formula
- Calculate total workout volume
- Track best estimated 1RM across all sets
- Restart for another exercise
- Validate inputs for sets, reps, and weight
